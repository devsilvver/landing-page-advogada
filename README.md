### ✨ Funcionalidades

* **🏛️ Hero Section Imersiva:** Banner de alta qualidade com chamada para ação (CTA) clara para agendamento de consultas.
* **💼 Áreas de Atuação:** Apresentação dos serviços jurídicos (Direito de Família, Empresarial, Imobiliário, Criminal) com ícones personalizados.
* **🗣️ Prova Social:** Seção de depoimentos para aumentar a autoridade e confiança.
* **📱 Design Responsivo & Elegante:**
    * Layout adaptável para celulares e desktops.
    * Uso de tipografia refinada (*Playfair Display* para títulos e *Poppins* para textos).
    * Efeitos de navegação suave (*Smooth Scroll*) e Header que reage à rolagem.
* **✉️ Formulário de Contato:** Layout funcional para envio de mensagens e captação de leads.

---

### 🛠️ Tecnologias Utilizadas

* **[React 19](https://react.dev/)** - Biblioteca para construção da interface componentizada.
* **[TypeScript](https://www.typescriptlang.org/)** - Tipagem estática para maior segurança no desenvolvimento.
* **[Vite](https://vitejs.dev/)** - Build tool de próxima geração para desenvolvimento rápido.
* **[Tailwind CSS](https://tailwindcss.com/)** - Framework CSS *utility-first* para estilização ágil e moderna.

### 🚀 Como rodar o projeto

#### 1. Clone o repositório
```bash
git clone [https://github.com/devsilvver/landing-page-advogada.git](https://github.com/devsilvver/landing-page-advogada.git)
cd landing-page-advogada
```

#### 2. Instale as dependências
```bash
npm install
```

#### 3. Execute o projeto
```bash
npm run dev
```
O site estará disponível em `http://localhost:3000`.

